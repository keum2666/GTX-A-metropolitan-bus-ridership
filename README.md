# GTX-A 개통에 따른 서울행 광역버스의 이용 변화 분석

파주·고양시의 운정중앙역·킨텍스역·대곡역 권역을 대상으로, GTX-A 개통 전후 광역버스 승차 변화와 GTX역 연계버스 이용의 관계를 살펴보는 연구다. 출근시간대와 일일 분석을 각각 진행하며, 출근시간대는 **06:00 이상 10:00 미만**으로 설정하였다.

## 연구 배경

GTX-A가 개통되면서 경기도에서 서울로 이동할 때 기존 광역버스 외에 GTX역에 접근하여 철도를 이용하는 경로가 추가되었다. 이에 광역버스 승차가 어떻게 달라졌는지, 그 변화가 어떤 지역·교통 특성과 관련되는지 확인하고자 하였다. 또한 광역버스 승차 변화를 분석한 같은 격자에서 GTX역까지 버스로 이동하는 이용을 함께 살펴보며, 기존 광역버스 이용의 GTX 전환 가능성을 검토하였다.

## 사용 데이터

| 항목 | 내용 |
|---|---|
| 교통카드 자료 | 국토교통부 지역별 교통카드이용 합성데이터 |
| 비교 시점 | GTX-A 개통 전 2024년 10월 17일 / 개통 후 2025년 11월 6일 |
| 분석 대상 | 운정중앙역·킨텍스역·대곡역 권역의 250m 격자 126개 |
| 격자 선정 | 개통 전후 비교를 위해 광역버스 노선과 정류장이 동일하게 유지된 격자 선정 |
| 광역버스 | 분석격자에서 승차하여 서울에서 하차한 광역버스 기록 |
| GTX역 연계버스 | 분석격자에서 승차하여 운정중앙역·킨텍스역·대곡역 정류장에서 하차한 마을·시내버스 기록 |
| 지역·교통 특성 | GTX역까지 도보시간, IC 접근성, 목적지 중첩 비율, 평균 버스 통행시간, 인구·건축물·토지이용 및 기존 철도역 자료 |
| 현장조사 | 시민 인터뷰 및 세 역의 접근·환승 여건 답사 |

승차건수는 합성데이터의 기록 한 행을 1건으로 집계하였다. 광역버스 승차 변화량은 **개통 후 승차건수 − 개통 전 승차건수**이며, GTX역 연계버스는 개통 후 승차건수를 사용하였다. 권역별 이용은 승차 격자가 속한 권역을 기준으로 집계하였다.

광역버스 출근시간대 회귀분석은 개통 전 통행 특성을 산출할 수 있는 113개 격자, 일일 회귀분석은 126개 격자를 사용하였다. 연계버스 회귀분석과 순위상관분석은 0건인 격자도 포함한 126개 격자를 대상으로 하였다.

## 주요 결과

- **광역버스 승차 변화:** 출근시간대에는 3,098건에서 2,286건으로, 일일에는 7,110건에서 5,517건으로 감소하였다. 출근시간대에는 운정중앙·킨텍스 권역에서 감소하고 대곡 권역에서는 증가하여 권역별 차이가 나타났다.
- **광역버스 변화와 관련된 특성:** GTX역까지 도보시간이 짧고 광역버스의 목적지가 GTX의 서울 내 도착역 주변과 많이 겹치는 격자일수록 승차 변화량이 작았다. 출근시간대에는 IC 접근성과 주거지역 비율도 유의한 관계를 보였다.
- **GTX역 연계버스 이용:** 출근시간대 646건, 일일 1,015건이 관측되었으며 운정중앙 권역에 이용이 집중되었다. 출근시간대 회귀에서는 GTX역까지 도보시간, 주변 철도역 수, 건축물 연면적 및 운정중앙 권역 변수와 유의한 관계가 나타났다.
- **두 지표의 관계:** 두 시간대 모두 운정중앙·대곡 권역에서 광역버스 승차 변화량이 작은 격자일수록 연계버스 승차건수가 많은 음의 순위상관이 나타났다. 킨텍스 권역에서는 통계적으로 유의한 관계가 확인되지 않았다.

이 결과는 기존 광역버스 이용객이 GTX로 교통수단을 변경했을 가능성을 간접적으로 살펴볼 수 있는 공간적 관계다. 격자별 합성자료를 활용한 분석이므로 개별 이용자의 실제 전환이나 GTX 개통의 인과효과를 직접 확인한 결과는 아니다.
